# 图形化工具生成区

## 重要提示：自动生成代码

把 LVGL Pro Editor 或其他 LVGL 9.5 兼容工具导出的 .c/.h 文件放在这里。
重新运行 CMake/	ools/build.ps1 后，目录中的 .c 文件会自动加入构建。

### 关键规则

⚠️ **勿在生成文件内进行长期维护**
- 此目录中的所有 .c/.h 文件在设计工具重新导出时会被完全覆盖
- 下次导出将清除对生成代码的任何手工修改
- 业务逻辑、事件处理、数据访问必须放在 custom/ 子目录

📌 **文件分工**
- 自动生成的 _gen.c、_gen.h：设计工具输出，完全自动管理，**不要编辑**
- 编辑器生成的其他文件：结构定义与初始化代码，**极小化修改**
- 业务事件处理：custom/ 目录中编写自定义回调
- RT-Thread 数据访问和硬件调用：custom/ 目录中编写驱动接口

### 工作流程

1. 在 LVGL Pro Editor 中设计 UI
2. 导出为 C 代码，放入本目录
3. 修改需求时，重复导出（覆盖整个目录）
4. 在 custom/ 中维护事件处理和硬件交互代码
